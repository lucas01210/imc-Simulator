# 游戏设计文档（Game Design）

## 1. 设计理念

这是一款“策略可玩的教学模拟器”。核心不是追求真实投放准确率，而是用可解释的因果链路让玩家理解 IMC：

- **覆盖与触达（广告/媒介策略）** → 提升 `认知`
- **内容与互动（内容/社媒联动）** → 提升 `理解`（简化为认知质量/考虑）
- **可信背书（公关/利益相关者沟通）** → 提升 `信任`
- **转化动作（销售促进/渠道协同）** → 推动 `销量`
- **口碑扩散与舆情（UGC/媒体/社群）** → 影响 `舆情` 与长期 `口碑资产`
- **危机传播（危机预案）** → 降低负面扩散并恢复信任

同一回合内，不同渠道不是“叠加数值”，而是存在联动与冲突：
- 广告提升曝光但不等于信任；
- 公关与内容提供可信叙事，但离散执行会损失效率；
- 销售促进能提升销量，但过度可能伤害长期品牌资产（例如透支溢价与信任）。

## 2. 核心系统概览

### 2.1 主要指标（Metrics）

建议在 MVP 中实现这些数值（0-100 或带上下限）：

1. `认知`：曝光与理解的初级结果
2. `信任`：可信度与满意度的综合简化
3. `舆情`：公众情绪/媒体与社群口碑的净值（可正可负）
4. `销量`：转化结果（受认知、信任、渠道转化效率影响）
5. `预算`：回合可用资源（决定能做什么决策）
6. `团队协同`：执行效率/跨部门一致性（决定联动加成是否打折）
7. `长期品牌资产`：衡量未来增长潜力（受舆情、信任、过度促销/危机恢复影响）

可实现为：
- 当前值 `current`
- 每回合变动 `delta`
- 变化原因由事件日志呈现

### 2.2 回合制流程

每局设置 `N=5` 或 `N=8` 回合（MVP 推荐 5 便于演示）。

每回合包含：
1. **决策阶段**：玩家选择 `2` 张决策卡（MVP 首选 2）
2. **验证阶段**：检查预算与前置条件（如“危机预案”需要舆情低于阈值时才更有效）
3. **结算阶段**：引擎根据决策与当前指标生成事件，并更新指标
4. **教学阶段**：将本回合事件映射到 IMC 教学解释（短解释+可展开）
5. **进入下一回合**：如果回合未结束，进入下一轮决策；否则进入结局页

## 3. 品牌类型（Brand Types）

MVP 至少提供 2-3 类品牌类型，每类不同参数影响初始指标与事件权重。

建议示例（可根据你后续偏好调整）：

1. **快消/高频品牌**
   - 更看重：短期销量、渠道促销效果
   - 风险：过度折扣会伤害长期资产与信任
2. **科技/高信任品牌**
   - 更看重：内容教育、可信背书、公关信誉
   - 风险：如果媒介策略不当，认知增长慢但舆情影响更强
3. **本地服务/关系型品牌**
   - 更看重：利益相关者沟通、社区舆情
   - 风险：团队协同差时会导致执行割裂，造成信任波动

品牌类型影响：
- 起始 `团队协同`
- 决策卡的效果系数
- 事件出现概率与触发阈值

## 4. 决策卡系统（Decision Cards）

每张决策卡属于一个 IMC 模块，并带有：
- `cost`：预算消耗
- `effects`：对指标的基础变化方向（正/负/条件）
- `teachingTag`：IMC 教学点（如：曝光→认知；可信背书→信任）
- `synergy`：与其他模块组合时的联动加成

MVP 决策模块建议至少 4-6 类（但每回合只选 2 张）：
1. `广告投放（覆盖/触达）`
2. `媒介策略（渠道选择/频次/受众定向）`
3. `内容社媒联动（教育内容/互动节奏）`
4. `公关议题（媒体与利益相关者沟通）`
5. `销售促进（优惠/试用/促销机制）`
6. `危机预案（舆情修复/声明与补救动作）`

### 4.1 联动与冲突（IMC 机制）

系统应支持至少两种典型联动：

1. 广告 + 内容
   - 联动：提高认知质量（不仅“看过”，还能“理解”）
2. 内容/广告 + 公关
   - 联动：从认知走向信任（可信叙事与一致信息）
3. 销促 + 广告/渠道
   - 冲突：如果信任不足，销量提升会以负面舆情形式回灌，长期资产受损

团队协同作为联动折扣项：
- 如果玩家本回合选的两张卡属于不同部门/节奏，且团队协同低，则联动加成衰减

## 5. 事件与教学反馈（Events & Teaching Logic）

每次结算引擎生成 1-3 条事件。每条事件包含：
- `eventId`
- `triggeredBy`（由哪些决策卡触发/放大）
- `delta`（影响哪些指标及幅度）
- `teachingExplanation`（IMC 解释文本）
- `impactType`（正面/负面/中性/混合）

### 5.1 典型事件模板（示例）

1. **认知跃升（广告 + 合适媒介）**
   - 原因：触达提升导致 `认知` 快速增长
   - 教学：媒体选择决定“到达率与有效触点质量”
2. **信任建立（公关 + 内容一致叙事）**
   - 原因：可信背书降低不确定性
   - 教学：公关是“减少认知偏差”，内容是“提供理解路径”
3. **销量拉升但口碑波动（促销过度）**
   - 原因：短期转化提升，但舆情可能下滑（顾客体验与价值感差）
   - 教学：销售促进需要与品牌资产保护策略同步
4. **舆情危机（危机预案或负面舆情随机）**
   - 原因：舆情触发负面扩散
   - 教学：危机传播关键在“速度、透明度、行动一致性”

## 6. UI/动画反馈设计（Pixel & Motion）

MVP 需要视觉反馈，但不追求复杂资产：

1. 指标变化
   - 数字跳动（CSS keyframes），同时发光提示 `+x` / `-x`
2. 决策卡翻转
   - 选择后卡片翻面“已锁定”，可配合 Framer Motion 的弹入
3. 事件时间线
   - 新事件以像素滑入动画出现
4. 回合结算弹层
   - 用像素边框容器 + 轻微震动提示“结算完成”

精灵/占位方式：
- 使用 `div` + CSS 背景网格模拟像素角色（例如“CMO 头像”）
- 图标先用 `public/sprites/` 的简单 SVG/PNG 占位或纯 CSS 像素块

## 7. 结局与能力评估

终局综合指标与趋势决定结局类型（示例）：

1. **增长稳健型**：认知+信任同步提升，舆情稳定，长期资产增长
2. **短期冲量型**：销量高但信任/长期资产下滑，舆情可能偏负
3. **舆情失控型**：舆情持续下滑或危机恢复失败，信任被消耗
4. **危机反转型**：危机预案得当，负面舆情被控住，信任回升

能力评估维度（建议输出 3-5 项，便于教学）：
- `跨渠道一致性`：是否出现“广告强但公关缺位”等失衡
- `资源配置纪律`：预算是否合理，是否出现透支导致后续无力
- `风险控制`：舆情波动是否被及时处理
- `长期资产意识`：是否避免让销量以负面口碑为代价
- `团队协同执行`：是否通过选择联动卡提升协同效率

复盘建议应基于“本次决策失误链条”，例如：
- “你在信任尚未建立时重促销，导致短期销量高但舆情回灌为负”
- “建议下一局优先在第 1-2 回合用内容+公关建立信任底盘”

## 8. 难度与数值平衡（MVP 简化）

MVP 为了可玩性，不需要复杂随机数模型。建议：
- 每个决策卡给出固定方向的 `baseDelta`
- 再根据当前指标差异做缩放（例如信任越低，公关带来的提升越大或更必要）
- 舆情危机用简单阈值：当 `舆情 < 某值` 时触发危机概率提升

目标是让不同策略能明显拉出不同曲线，但不会出现“全局必败/必胜”。
