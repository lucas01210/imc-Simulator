# 产品需求文档（PRD）

## 1. 背景与问题

在品牌管理与整合营销传播（IMC）教学中，很多概念停留在“渠道单点理解”或“策略描述”，但缺少一种能把多渠道联动、资源约束、舆情反馈、信任建立与长期品牌资产综合起来的互动方式。

传统案例复盘往往是回顾式且无法让学习者“亲手做决策—承担结果”。因此需要一个可离线运行的网页模拟器，让学习者在回合制环境中理解 IMC 的因果链路。

## 2. 产品目标（Objectives）

1. **让学习者掌握 IMC 的“跨渠道联动思维”**：广告、公关、内容与销售促进之间如何共同影响认知—信任—转化—口碑—长期资产。
2. **把策略变成决策**：用户以决策模块的形式选择投放、议题、公关动作、内容节奏、渠道与协同，而不是仅阅读文字。
3. **输出可解释的反馈**：每个关键指标变化都附带 IMC 解释（对应渠道/利益相关者机制）。
4. **形成“可复盘”的学习闭环**：回合内的事件日志 + 结局评价 + 复盘建议。
5. **离线可玩**：第一版无需后端，用 `localStorage` 保存进度。

## 3. 核心用户画像（Personas）

1. **营销/品牌/传播从业者（教学与训练型）**
   - 诉求：用低成本方式演练策略组合，学习跨渠道联动的风险与收益。
2. **市场与管理学生（课堂补充型）**
   - 诉求：把 IMC 概念转化为“决策—结果—原因”的可视化训练。
3. **产品/创业团队（策略演练型）**
   - 诉求：在预算与风险约束下做“策略一致性”和“风险控制”训练。

## 4. 关键使用场景（Use Cases）

1. **课程作业/课堂演练**
   - 教师指定品牌类型，学生完成若干回合决策并提交复盘。
2. **个人学习**
   - 通过多次开局比较不同策略组合对长期资产的影响。
3. **团队培训**
   - 会议中用离线模拟快速讲解“资源分配”和“危机传播预案”的价值。

## 5. 产品价值主张（Value Proposition）

- **因果化学习**：同样是“投放+内容+公关”，策略组合为何导致不同舆情与信任结果，系统会解释。
- **跨渠道联动**：不是单一渠道加成，而是 IMC 链路（覆盖→理解→信任→转化→口碑扩散→长期资产）。
- **教学与可玩并重**：视觉反馈（像素动画）与教学解释共同存在。
- **离线可运行**：无需部署后端，降低使用门槛。

## 6. 成功指标（Success Metrics）

1. **可用性**
   - 95%+ 的可操作路径不报错（离线、刷新可恢复）。
2. **学习有效性（可观测）**
   - 用户能在结局报告中指出至少 2 条“策略与结果的因果关系”（系统可用教学提示引导）。
3. **策略深度**
   - 不同策略在指标曲线上呈现差异（例如短期销量 vs 长期资产的取舍）。
4. **留存（后续可选）**
   - 同一用户在不同开局至少尝试 2 次不同策略组合。

## 7. 范围界定（Scope）

### MVP 范围

- 离线回合制模拟
- 至少 2-3 类品牌类型
- 每回合若干决策模块（建议 2 张起步，MVP 更易演示）
- 指标更新 + 事件日志 + 教学解释
- 结局页面：结局类型、能力评估、复盘建议
- 本地存档（单存档槽）
- 像素风 UI 与基础动画反馈

### MVP 不在范围（Non-scope）

- 后端服务、多人对战、排行榜（后续需要后端再做）
- 高复杂度真实投放/舆情模型（先用可解释的简化规则）
- 复杂角色扮演（先聚焦 CMO 决策与跨渠道逻辑）

## 8. 产品需求（PR Requirements）

### 8.1 用户故事（User Stories）

1. 作为玩家，我可以选择品牌类型并开始一局游戏。
2. 作为玩家，我可以在每回合选择决策模块，并确认我的选择。
3. 作为玩家，我可以查看每回合的指标变化与事件日志，并理解原因（教学解释）。
4. 作为玩家，我可以在结束后看到结局类型与能力评估，并获得复盘建议。
5. 作为玩家，我可以在刷新/重新打开后继续当前存档。

### 8.2 关键交互与页面

1. `首页`：项目介绍、开始按钮
2. `选择品牌`：品牌类型卡、难度/风险提示
3. `游戏主界面`：指标面板、决策卡、事件日志、回合推进按钮
4. `结算/结局页面`：结局卡、能力评估雷达/条形、复盘建议

## 9. 用户旅程（User Journey）

首页 → 选择品牌 → 回合 1- N 决策 → 回合结算与事件日志 → 终局结算 → 能力评估与复盘 → 可重开或继续

## 10. 优先级策略（Prioritization）

P0（必须有）：
- 离线回合制逻辑
- 决策模块选择与结算
- 指标变化可解释
- 结局与复盘输出

P1（建议有）：
- 舆情/危机事件（简化版）
- CSS/Framer Motion 动画反馈

P2（可后续）：
- 多存档槽、挑战模式、更多品牌类型、难度系统

## 11. 风险与缓解（Risks）

1. **策略组合太复杂导致理解困难**
   - 缓解：MVP 强制每回合只选少量决策，并为每张卡提供清晰 IMC 解释。
2. **数值模型失衡（好策略/坏策略无法区分）**
   - 缓解：提前定义指标范围与变化速度；通过多次模拟观察指标曲线形态。
3. **教学解释过长影响可玩性**
   - 缓解：教学解释用短句+可展开段落；结局页提供更完整复盘。
