# UI 风格指南（像素风教育模拟器）

## 1. 视觉目标

- 现代像素风：不要“幼稚卡通”，避免圆润大面积渐变。
- 教育模拟器语气：信息密度适中、结构清晰，强调“指标变化 + IMC 理由”。
- 可演示：关键反馈必须可见（数值跳动、卡片锁定、结算弹层等）。

## 2. 颜色与对比度

推荐使用的基础色（与当前 Tailwind 样式一致）：

- 背景：`#070a0f`
- 面板：`#06080d`
- 主强调（薄荷绿）：`#00ffaa`
- 文字：`#e8eef6`
- 次要文字：`#a8b3c7`
- 细节文字：`#7f8aa3`
- 警告：`#ffd166`
- 危险：`#ff4d6d`

规则：

- 主信息必须达到可读对比（尤其在小屏上）。
- 警示/负面使用 `warn/danger` 色系，并配合像素边框。

## 2.1 全局 Token 约定

本项目约定通过以下 token 维持统一外观（用于新组件快速接入，避免随意选色）：

- 颜色：`IMC_THEME`（例如 `mint/text/muted/warn/danger`）
- 字体：`IMC_TYPO.fontFamilyMono`
- 间距：`IMC_SPACING`（用于文案与组件密度的参考）

## 3. 像素质感（不要过度依赖图片）

- 优先用 CSS/HTML + Tailwind 实现像素边框：方正、无圆角。
- 卡片与容器均使用固定的边框与“像素阴影”（`shadow-pixel` 类）。
- “精灵占位”优先使用 `div` + 背景色块，而不是复杂图片资产。

## 4. 组件规则（可复用）

1. `PixelButton`：像素按钮容器，hover 提亮、active 下压。
2. `PixelCard`：内容容器，作为信息块的基底。
3. `PixelPanel`：面板容器，顶部带标题与 hint 文案。
4. `PixelBadge`：用于状态/模块标签；必须短且可扫读。

## 5. 动画与反馈

优先级：

1. 指标变化数字：使用 CSS keyframes（跳动 + 发光）。
2. 事件/卡片：滑入、翻转、置灰（锁定状态）。
3. 结算弹层：轻微震动 + 呼吸发光。

约束：

- 动画不得遮挡关键信息（例如指标面板、事件标题）。
- 保持“轻量”：优先 CSS 动画，其次 Framer Motion。

## 6. 文案与教学结构

每个事件的教学解释建议拆成三段：

1. 发生了什么（短句）
2. IMC 机制是什么（关键因果）
3. 下一步怎么做（策略建议）

避免：

- 长篇段落堆叠在事件卡上。
- 只讲“做法”，不讲“为什么有效/为什么会反噬”。
