# IMC 模拟器（IMC Simulator）

一个用于教学与可玩性的**网页像素风《整合营销传播（IMC）》决策模拟器**。
玩家扮演不同类型品牌的 CMO，在真实的营销传播环境中做跨渠道决策，并观察这些决策如何影响：
品牌认知、信任、舆情、销量、预算、团队协同、长期品牌资产等关键指标；最终给出结局与能力评估，并提供复盘建议。

> 目标：第一版先做**本地离线版**（无后端），确保可运行、可演示、可逐步扩展。

---

## 目标用户

1. **营销/品牌/传播从业者**：希望用“可模拟”的方式理解 IMC 链路与跨渠道联动。
2. **市场与管理学生**：需要将课堂概念（广告、公关、销售促进、媒介策略等）转化为可操作决策。
3. **产品/创业团队**：用轻量方式做营销策略演练，训练“指标—决策—解释”的思维闭环。

---

## 核心玩法（离线回合制）

1. **选择品牌类型**（不同类型会影响起始资产、风险偏好与事件分布）。
2. **进入回合**：每回合玩家选择若干“决策模块”（例如广告投放、公关议题、内容/社媒联动、销售促进、媒介策略、危机预案与协同等）。
3. **引擎结算并生成事件日志**：每个事件都以 IMC 理由解释“为什么会这样”，并以像素风 UI 动画反馈指标变化。
4. **多回合后结局**：系统综合指标给出结局类型（例如：增长稳健型、品牌透支型、舆情失控型、危机反转型等），并进行能力评估与复盘建议。
5. **本地存档**：所有进度保存在浏览器 `localStorage`，无需后端即可继续游戏。

## 技术栈

- **Next.js（App Router）**
- **React + TypeScript**
- **Tailwind CSS**
- **Framer Motion**（用于状态切换/弹层/回放过渡）
- **CSS 动画**（用于像素风数字跳动、卡片翻转、像素精灵占位反馈）

## 本地运行

1. 安装依赖

```bash
npm install
```

2. 启动开发服务器

```bash
npm run dev
```

如果你想指定端口（例如避免端口占用）：

```bash
npm run dev -- --port 3001
```

3. 构建生产版本（可用于验证部署流程）

```bash
npm run build
```

4. 启动生产服务器（本地预览用）

```bash
npm run start -- --port 3002
```

## 版本与扩展方向

第 1 版（MVP）优先级：

1. 离线可玩：无后端、可演示
2. 可解释：每次指标变化都有 IMC 教学理由
3. 可扩展：决策卡、事件模板、品牌类型、教学说明都以数据驱动方式维护

后续版本可能扩展：

- 更多品牌类型与细分行业设定
- 更复杂的舆情扩散与危机联动
- 多存档、多难度与评分体系
- 可选：教学模式（逐步引导）与挑战模式（限定预算/限定决策）
- 可选：服务端回测与排行榜（需要后端时再引入）

## 环境变量

本项目在 MVP 阶段**不需要任何后端环境变量或数据库配置**。

可选（用于关闭 Next.js telemetry）：

```bash
NEXT_TELEMETRY_DISABLED=1
```

---

## 部署到 Vercel

本项目是典型 Next.js 前端应用，可直接部署到 Vercel（无后端、仅构建产物）。

你只需要：

1. 在 Vercel 创建新项目，导入本仓库
2. Framework 选择 `Next.js`
3. Build Command 使用默认的 `npm run build`
4. Output/Start 配置使用 Next.js 默认策略（Vercel 会自动处理 `next start`）

通常情况下不需要手动设置环境变量。
